### About

Full Stack Engineer with a backend focus. I build APIs, queues, payment flows and real-time systems, and I take legacy products (Delphi, low-code, .NET) to modern, testable architectures without stopping the business.

Today I work as a contractor through my company, **DL Software**, on video commerce, generative AI and ISP products.

### What I'm working on

- **Lis Video AI** — rebuilt from a legacy app into a NestJS + Fastify API and worker (pg-boss, PostgreSQL, S3) with an Angular SSR front end. Payments via Safe2Pay, invoicing via Omie, 100% test coverage with Testcontainers.
- **lis-compressor** — video transcoder in **Rust** (axum, tokio, sqlx, ffmpeg) that outputs HLS in up to 4 qualities with resumable S3 uploads. It replaced a .NET + AWS MediaConvert pipeline and runs on EKS and Cloudflare R2 with AWS failover.
- **ISP platform (Funny Internet)** — subscriber app in React Native (Expo) with a NestJS BFF, automated credit-bureau (SCPC) collections, and a multi-tenant omnichannel chat built with Socket.IO, PostgreSQL RLS, outbox + BullMQ and Next.js.
